# Sell me this!

Несбалансированные клики. Куча категорий. Выбросы, от которых едет метрика. Шесть цифр, которые все можно предсказывать. И это не пять разных домашек — **одна выгрузка из Директа**.

Типичный учебный csv тут заканчивается на третьей ячейке: клика нет в 87% строк, заказ не случился ни разу, wCTR иногда 1900%, а «группа» — это кампания, не полка в магазине. One-hot из учебника раздует таблицу. Средний CTR по строкам соврёт. Зато на этом можно честно потренироваться: выбрать цель, не спутать объект, побить константу.

Данные — `dataset/bycicles.csv`: поиск, велосипеды Centra Market, Иркутск и область, ~10 тысяч строк, лето 2023 и весна 2024.

## Установка

Нужны [Miniconda](https://docs.conda.io/en/latest/miniconda.html) или Anaconda. Из корня репозитория:

```bash
conda env create -f environment.yml
conda activate sell-me-this
python -m ipykernel install --user --name sell-me-this --display-name "Python (sell-me-this)"
```

Если среда уже была, а `environment.yml` обновился:

```bash
conda env update -f environment.yml --prune
conda activate sell-me-this
```

В Cursor / VS Code выберите ядро `Python (sell-me-this)`.

Туториал `tutorials/shap.ipynb` отдельно просит `torch`, `torchvision` и `transformers` — в эту среду они не входят.

## Описание метрик

Шесть штук в одной строке. Они про одно и то же событие, поэтому «предсказать всё» — ещё не значит «сделать шесть моделей».

**Показы** — сколько раз объявление показали в этой клетке отчёта. Часто равно 1.

**Взвешенные показы** — те же показы с весом аукциона (позиция и прочее). Один физический показ может считаться как 0.05 взвешенного.

**Клики** — сколько раз по объявлению кликнули в этой клетке.

**CTR (%)** — клики / показы внутри клетки, в процентах. При одном показе это 0 или 100. Для сравнения сегментов считают заново: \(100 \times \sum клики / \sum показы\).

**wCTR (%)** — клики / взвешенные показы. Когда вес далёк от 1, колонка расходится с CTR и может быть больше 100%.

**Расход (руб.)** — сколько списали за эту клетку.

**Конверсии** — товар в корзине, оформленный заказ, лид с сайта. В этой выгрузке заказов нет, корзин и лидов единицы. Прочерк в ячейке — не число, а «события не было».
