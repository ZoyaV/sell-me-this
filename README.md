# Sell me this!

Курс по рекламным данным и моделям. Семинары идут на одной выгрузке из Яндекс Директа: магазин велосипедов Centra Market (Иркутск и область), поиск, лето 2023 и весна 2024.

Файл — `dataset/bycicles.csv`, около 10 тысяч строк. Строка здесь не человек и не объявление, а клетка отчёта: объявление × день × пол × возраст × устройство × тип запроса. В клетке часто один показ, поэтому `CTR (%)` в строке легко становится 0% или 100%. Долю кликов, о которой можно говорить, считают так: сумма кликов / сумма показов по сегменту.

Группы вроде «Велосипед Детский» или «Велосипед Купить» — это кампании в Директе, не типы велосипедов в каталоге.

## Установка

Нужны [Miniconda](https://docs.conda.io/en/latest/miniconda.html) или Anaconda. Из корня репозитория:

```bash
conda env create -f environment.yml
conda activate sell-me-this
python -m ipykernel install --user --name sell-me-this --display-name "Python (sell-me-this)"
```

Если среда уже была, а `environment.yml` обновился:

```bash
conda env update -f environment.yml --prune
conda activate sell-me-this
```

В Cursor / VS Code выберите ядро `Python (sell-me-this)`.

Туториал `tutorials/shap.ipynb` отдельно просит `torch`, `torchvision` и `transformers` — в эту среду они не входят.

## Какие будут семинары

1. **Как устроена таблица** — `seminars/look_at_data_processing.ipynb`: чистка, распределения, корреляции, VIF, label / one-hot.
2. **Что считает строка** — `seminars/look_at_data_eda.ipynb`: зерно выгрузки, доли кликов по срезам, время, текст объявления.
3. **Бейзлайн CTR** — `seminars/look_at_data_task.ipynb` и `look_at_data_solution.ipynb`: предсказать долю кликов группы за день наборами `if`, проверка в `look_at_data_checks.py`.

Дальше по плану курса — линейные модели, классификация и деревья (материалы прошлого года лежат в `seminars_2025/`).

## Описание метрик

Это колонки из `bycicles.csv`, не абстрактный словарь KPI.

**Показы** — сколько раз объявление показали в этой клетке отчёта. Часто равно 1.

**Взвешенные показы** — те же показы с весом аукциона (позиция и прочее). Один физический показ может считаться как 0.05 взвешенного.

**Клики** — сколько раз по объявлению кликнули в этой клетке.

**CTR (%)** — клики / показы внутри клетки, в процентах. При одном показе это 0 или 100. Для сравнения сегментов считают заново: \(100 \times \sum клики / \sum показы\).

**wCTR (%)** — клики / взвешенные показы. Когда вес далёк от 1, колонка расходится с CTR и может быть больше 100%.

**Расход (руб.)** — сколько списали за эту клетку.

**Конверсии** — товар в корзине, оформленный заказ, лид с сайта. В этой выгрузке заказов нет, корзин и лидов единицы. Прочерк в ячейке — не число, а «события не было».
